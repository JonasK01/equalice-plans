# Image + A+ Plan Generator — Team-Anleitung (5 Minuten)

Dieses Tool erstellt **Image-Pläne + A+ Premium-Pläne** (die Kreativ-/Bildregie für das
Design-Team) — EQUALICE-gebrandet, mit automatischer Compliance- und Copy-Längen-Prüfung.

> **Wichtig:** Das Tool schreibt **keinen SEO-Text.** Titel + Bullets kommen aus dem
> SEO-Sheet (Arbeit des SEO-Teams) und werden 1:1 übernommen. Das Tool generiert nur die
> **Kreativ-Pläne** (7 Bilder + 7 A+ Module + Q&A).

## So machst du einen Plan

1. **Öffne die App** (Link vom Admin) und melde dich ggf. mit dem Team-Passwort an.

2. **Marke wählen** (oben „Active customer"). Ist die Marke neu? → Tab **Customers →
   + New customer**: Name, Marktplatz, Farben, Voice, Foto-Regeln, No-Gos, Logo hochladen.
   - **„New brand"** anhaken → das A+ bekommt **kein Vergleichs-Modul**, sondern ein
     **„From the Brand"-Banner** als Modul 7. Dazu die coole **Brand-Statement**-Zeile eintragen.

3. Zu **„Generate Image + A+ plan"** wechseln → das **SEO-`.xlsx`** des SKU hochladen.
   - Die App zeigt: gefundene USPs, Reviews, Keywords — und ob **SEO-Titel/Bullets** aus dem
     Sheet übernommen wurden (Hinweis „📋 SEO copy taken from the sheet").

4. **„Generate PDF"** klicken. Die KI schreibt die 7-Bilder-Regie + 7 A+ Module + Q&A in
   der Markenstimme (SEO-Copy bleibt unangetastet). Dauer ~1–3 Min.

5. **Ergebnis prüfen:**
   - ✅/⛔ **COMPLIANCE** — bei ⛔ (blocking) **nicht veröffentlichen**, Copy anpassen.
   - ✅/⚠️ **COPY LENGTHS** — Overlays sollen ≤30 Zeichen / ≤5 Wörter sein.
   - **PDF herunterladen** und ans Design-Team geben.

## Faustregeln (Qualität)

- **On-Image-Text ist eine Headline, kein Satz.** Kurz, stark, glanceable.
- **„Warum WIR?"** in jedem Bild — Badge/Contents/Nutzen, nie nacktes Produkt auf Weiss.
- **Ehrlich bei Reviews:** die häufigsten Kritikpunkte im Plan aktiv entkräften.
- **Compliance zuerst** — besonders bei Supplements/Kosmetik nur erlaubte Claims.
